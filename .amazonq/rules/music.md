지금부터 내가 올린 프로젝트 문서와 개발 일정 문서,
그리고 예상 결과 화면을 참고해서
악기 연습 관리 프로그램 개발을 도와줘.

나는 이 프로젝트를 직접 코딩하면서 배우려고 한다.
코딩 초심자라고 생각하고 설명해줘.

[참고 자료]

프로젝트 기획/기능 문서

개발 일정 문서

UI 예상 결과 화면 (이미지 안보일수 있음)

먼저 세 자료를 모두 확인하고 프로젝트의 전체적인 내용을 이해해줘.

특히 개발 순서는 내가 작성한 "개발 일정 문서"를 기준으로 진행한다.
개발 순서를 임의로 변경하거나 새로운 개발 일정을 만들지 마.

프로젝트 기능이나 화면에 대한 내용은 프로젝트 문서를 기준으로 하고,
UI 디자인은 첨부한 예상 결과 화면과 아래의 디자인 규칙을 기준으로 한다.

문서에 없는 기능이나 내용을 임의로 추가하지 말고,
필요한 변경사항이 있다면 먼저 나에게 설명하고 확인을 받아줘.

아직 코드를 작성하지 말고,
세 자료를 확인한 뒤 현재 프로젝트를 어떻게 이해했는지 간단하게 정리해줘.
그 다음 내가 개발 일정에 따라 첫 번째 작업을 요청하면 그때부터 개발을 시작하자.

[개발 방식]

나는 코딩 초심자이므로 배우면서 직접 코딩한다.

코드를 한꺼번에 많이 작성하지 않는다.

한 번에 1~2개의 파일 정도만 다룬다.

내가 직접 따라 작성할 수 있도록 코드를 단계적으로 보여준다.

코드만 보여주지 말고 각 코드가 왜 필요한지 설명한다.

설명은 초심자가 이해할 수 있는 쉬운 용어를 사용한다.

기존 코드를 수정할 때는 무엇을 왜 수정하는지 설명한다.

한 단계가 끝나면 내가 직접 실행하고 확인한 뒤 다음 단계로 넘어간다.

오류가 발생하면 전체 코드를 새로 작성하지 말고 오류 원인부터 찾는다.

기존 프로젝트의 파일 구조와 코드를 먼저 확인한 후 필요한 부분만 수정한다.

변수명, 함수명, 클래스명 등은 기존 프로젝트와 일관성을 유지하고 간단 명료하게 한다.

내가 이해하지 못한 부분이 있으면 해당 부분을 먼저 설명하고 진행한다.

내가 "다음 단계"라고 하기 전까지는
현재 작업 범위를 넘어가지 않는다.

악기 연습 관리 프로그램의 전체 UI 디자인을 만들어줘.

디자인 방향은 Songsterr의 악보 프로그램처럼
깔끔하고 심플하며 음악 프로그램 느낌이 나도록 해줘.

단, Songsterr의 화면을 그대로 복제하지 말고
전체적인 분위기와 UI 구성 방식만 참고해줘.


[디자인이 필요한 화면 목록]
1. 메인 화면 (허브) - 곡 목록, 최근 연습 요약
2. 곡 관리 - 곡 목록 / 등록 / 수정 / 삭제
3. 목표 관리 - 곡별 목표 설정, 달성률 표시, 미완료 목표 목록
4. 연습 진행 - 타이머 (시작/종료), 종료 시 숙련도 별점 입력 팝업
5. 통계 & 숙련도 - 기간별/곡별/요일별 그래프, 숙련도 변화 추이


[Layout]
- 왼쪽에 고정된 사이드바, 화면 높이 전체를 차지
- 오른쪽에 페이지 콘텐츠
- 사이드바 메뉴: 홈, 곡 관리, 연습하기, 통계
- 페이지 상단에는 현재 페이지 제목
- 콘텐츠 영역은 넓고 여백이 있는 구조


[Color & Theme]
Songsterr의 전체적인 색상 분위기를 참고해서
흰색과 밝은 하늘색을 중심으로 한 깔끔한 디자인으로 구성해줘.

- 전체 배경: 흰색 (#FFFFFF)
- 사이드바: 밝은 하늘색 (#20A9E8 계열), 아이콘/글자는 흰색
- 주요 버튼: 밝은 하늘색 / hover 시 조금 더 진한 하늘색
- 카드와 입력 영역: 매우 연한 회색 또는 흰색
- 기본 글자: 짙은 회색 (#444444) / 보조 글자: 중간 회색 (#888888)
- 구분선: 매우 연한 회색 (#E5E5E5)

전체 색상은 흰색 + 밝은 하늘색을 중심으로 제한하고,
그 외 보라색, 빨간색, 노란색 등의 강한 색상은 기본 디자인에 사용하지 않는다.

단, 목표 상태 표시에는 아래 색상을 예외적으로 허용한다.
- 진행전: 회색
- 진행중: 하늘색
- 완료: 초록색
- 미완료: 주황색

숙련도는 색상 대신 별(★) 개수로 단계를 표현하므로 별도의 색 구분은 필요 없다.

전체적으로 밝고 가벼우며 깔끔한 음악 프로그램 느낌을 유지한다.


[Design Style]
- 카드와 버튼을 과도하게 둥글게 만들지 않는다
- 그림자 효과를 최소화한다
- 그라데이션을 사용하지 않는다
- 장식적인 이미지나 배경 패턴을 최소화한다
- 아이콘은 단순한 선형 아이콘 스타일을 사용한다
- 글꼴은 깔끔하고 읽기 쉬운 산세리프체를 사용한다
- 정보가 복잡해 보이지 않도록 페이지마다 핵심 내용만 배치한다
- 음악 프로그램답게 콘텐츠에 집중할 수 있는 UI를 만든다
  
- 앞으로 DB 관련 작업할 때 MySQL Workbench 기준으로 설명한다.
